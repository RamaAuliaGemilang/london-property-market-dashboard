# London Property Market Dashboard 🏠

## 📌 Project Overview

An interactive **Streamlit dashboard** for exploring the London property market. The dashboard provides insights into property prices, property types, building age, interior styles, views, and materials.

Users can interactively filter the data based on various property characteristics and explore the resulting analysis through interactive visualizations.

## 🔎 Dashboard Features

* Property and price filtering
* Neighborhood analysis
* Bedroom, bathroom, and floor filters
* Garden, garage, heating, and balcony filters
* Building status filtering
* Total property count
* Average property price
* Average property size
* Price distribution by neighborhood
* Average price by property type
* Average price by building age
* Interior style and view distribution
* Material frequency analysis
* Top 3 most expensive properties
* Top 3 cheapest properties

## 📊 Visualizations

The dashboard uses interactive charts to analyze:

* Property price distribution
* Average price by property type
* Average price by building age
* Interior style and view distribution
* Material frequency

## 🚀 Run the Dashboard

Install the required dependencies:

```bash
pip install streamlit pandas plotly
```

Run the Streamlit application:

```bash
streamlit run main.py
```
